# Устранение проблем

- «не открыла порт N за 25 с» → порт отладки задаётся только при старте Chrome:
  закрыть копию и перезапустить через `open_browser.py` / `ensure_browser`.
- Chrome не найден → указать `chrome_path` в `browsers.json`.
- Профиль заблокирован (`SingletonLock`) → копия уже запущена: проверить `--status`.
- WS-подключения отдают 403 → копия запущена без `--remote-allow-origins=*`
  (старый запуск): перезапустить копию через `open_browser.py`.
- Копия отвечает на порт, но DevTools мёртв (залипшая копия, типично после
  гибернации) → `stop_copy(copy)` перезапустить; attach стоит в 3 попытки,
  лог — `chromedriver.log`.
- Chrome с профилем копии запущен без порта → `ensure_browser` падает: закрыть
  ту копию и запустить заново через `open_browser.py`.
